# Взаимодействие с объектами

Наведите центральную точку на коробку и нажмите E. Подсказка появляется, если поверхность находится не дальше 2.5 метра от камеры. Стены и другие блоки перекрывают доступ. Действие срабатывает один раз за нажатие; сообщение остаётся на 3 секунды, даже если отвернуться.

На карте `maze` можно осмотреть три коробки в подвале B1. Слева от старта находится запертая дверь в подвал, впереди справа - стойка с подсвеченным ключом. Наведитесь на ключ и нажмите E, затем так же откройте дверь. Ключ остаётся в инвентаре; его название видно в HUD. При перезапуске игры всё сбрасывается.

Дверь плавно уходит в стену за 0.9 секунды. Пока она движется, столкновения, луч выбора и тени следуют за панелью. Повторного закрывания пока нет. Без ключа дверь остаётся закрытой.

## Настройки

- `config/controls.py`, `interact` - клавиша. Подсказка берёт её имя из привязки.
- `config/settings.py`, `INTERACTION_REACH` - расстояние до поверхности объекта.
- `config/settings.py`, `INTERACTION_MESSAGE_SECONDS` - время показа ответа.

## Описание в карте

Для коробки в `resources/levels/maze.json`, `basement.boxes`, добавьте `interaction`:

```json
{
  "position": [-25.0, 0.35, 13.8],
  "size": [1.5, 0.7, 1.5],
  "material": "wood",
  "interaction": {
    "name": "Wooden crate",
    "action": "Inspect",
    "message": "The lid is nailed shut."
  }
}
```

`name` - название объекта, `action` - подпись действия (по умолчанию `Inspect`), `message` - ответ. Все строки должны быть непустыми. `action` меняет подпись. Поле `command` по умолчанию равно `inspect`; для объектов с состояниями игра также обрабатывает `pickup_key` и `unlock_door`, а `argument` содержит ID ключа. Без `interaction` блок остаётся обычной геометрией и продолжает перекрывать луч.

В коде тот же компонент можно передать любому `Box`: `interaction=Interaction(name="Crate", message="The lid is shut.")`. Доступность действия не зависит от материала или положения на конкретном уровне.

## Двери и ключи

Они описываются отдельно от статичных блоков, в корневом массиве `objects` карты `maze.json`:

```json
[
  {
    "id": "basement_key",
    "type": "key",
    "name": "Basement key",
    "key_id": "basement",
    "node": [0, 19, 1],
    "offset": [0.75, 0, -1]
  },
  {
    "id": "basement_door",
    "type": "door",
    "name": "Basement door",
    "key_id": "basement",
    "node": [0, 19, 0],
    "offset": [1.5, 0, 0],
    "axis": "z",
    "width": 1.8,
    "height": 2.35,
    "thickness": 0.18,
    "open_seconds": 0.9
  }
]
```

`id` должен быть уникальным. Совпадающий `key_id` связывает ключ и дверь; одним ключом можно открыть несколько дверей. `node` задаёт этаж, строку и столбец открытой клетки, `offset` - смещение XYZ в метрах от её центра на уровне пола. `axis` - ось ширины двери: `x` или `z`. Толщина идёт по другой горизонтальной оси. `open_seconds` - положительное время открытия в секундах, по умолчанию 0.9. Рама заполняет ширину клетки и высоту этажа. Для открытой панели нужно оставить место в стене на одну клетку в положительном направлении `axis`.

Ключ и дверь собираются из блоков, внешние модели пока не нужны. Ключ стоит на деревянной стойке, имеет отдельный удобный объём выбора и не мешает ходьбе. Стойка и дверная рама участвуют в столкновениях. Закрытая дверь блокирует игрока и луч; открытая панель уходит в стену и перестаёт быть препятствием.

## Код

- `engine/raycasting/aabb.py` - ближайшее пересечение луча с объёмными границами, расстояние и точка в мире. Буфер глубины не используется.
- `engine/scene/interaction.py` - подпись, ответ и команда действия.
- `engine/scene/object.py` - именованные состояния и плавные переходы между положениями блоков. Геометрия и столкновения обновляются вместе; правила дверей и ключей в движок не входят.
- `game/levels/objects.py` - создание двери, ключа, стойки и рамы из описания карты.
- `game/inventory.py` - ключи по ID и названия для интерфейса.
- `game/interactions.py` - выбор цели, препятствия, команды подбора и открытия, время показа ответа. Границы сохраняются до смены состояния; стены проверяются только при попадании луча в доступную цель.
- `game/entities/player.py` - обновляет выбор после движения и поворота камеры.
- `engine/rendering/hud.py` - центральная точка и подсказка с переносом длинного текста. Интерфейс рисуется после постобработки; текстура текста переиспользуется, пока текст не изменился.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe tools\check_interactions.py
```

GPU-проверка запускает игровой цикл рядом с настоящими коробками подвала: наведение, нажатие E, удержание, повторное нажатие, поворот и исчезновение сообщения. Проверяет разрешения 640x480 и 320x240, перенос текста, положение точки и масштабирование. Кадры и отчёт находятся в `artifacts/interaction-*`.
