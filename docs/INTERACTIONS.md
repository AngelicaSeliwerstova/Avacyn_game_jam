# Взаимодействие с объектами

Наведите центральную точку на коробку и нажмите E. Подсказка появляется, если поверхность находится не дальше 2.5 метра от камеры. Стены и другие блоки перекрывают доступ. Действие срабатывает один раз за нажатие; сообщение остаётся на 3 секунды, даже если отвернуться.

На карте `maze` осмотреть можно три коробки у входа в подвал B1. У каждой свой ответ. Сейчас действие показывает текст осмотра; открывание, перенос предметов и инвентарь ещё не реализованы.

## Настройки

- `config/controls.py`, `interact` - клавиша. Подсказка берёт её имя из привязки.
- `config/settings.py`, `INTERACTION_REACH` - расстояние до поверхности объекта.
- `config/settings.py`, `INTERACTION_MESSAGE_SECONDS` - время показа ответа.

## Описание в карте

Для коробки в `resources/levels/maze.json`, `basement.boxes`, добавьте `interaction`:

```json
{
  "position": [-25.0, 0.35, 13.8],
  "size": [1.5, 0.7, 1.5],
  "material": "wood",
  "interaction": {
    "name": "Wooden crate",
    "action": "Inspect",
    "message": "The lid is nailed shut."
  }
}
```

`name` - название объекта, `action` - подпись действия (по умолчанию `Inspect`), `message` - ответ. Все строки должны быть непустыми. `action` меняет подпись, а не запускает скрипт. Без `interaction` блок остаётся обычной геометрией и продолжает перекрывать луч.

В коде тот же компонент можно передать любому `Box`: `interaction=Interaction(name="Crate", message="The lid is shut.")`. Доступность действия не зависит от материала или положения на конкретном уровне.

## Код

- `engine/raycasting/aabb.py` - ближайшее пересечение луча с объёмными границами, расстояние и точка в мире. Буфер глубины не используется.
- `engine/scene/interaction.py` - описание осмотра.
- `game/interactions.py` - выбор цели, проверка препятствий и время показа ответа. Границы статичных объектов сохраняются при создании; стены проверяются только при попадании луча в доступную цель.
- `game/entities/player.py` - обновляет выбор после движения и поворота камеры.
- `engine/rendering/hud.py` - центральная точка и подсказка с переносом длинного текста. Интерфейс рисуется после постобработки; текстура текста переиспользуется, пока текст не изменился.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe tools\check_interactions.py
```

GPU-проверка запускает игровой цикл рядом с настоящими коробками подвала: наведение, нажатие E, удержание, повторное нажатие, поворот и исчезновение сообщения. Проверяет разрешения 640x480 и 320x240, перенос текста, положение точки и масштабирование. Кадры и отчёт находятся в `artifacts/interaction-*`.
