# Свет на карте

В `resources/levels/maze.json`, в разделе `lighting`, стоят 102 лампы. Холодные освещают проходы, тёплые выделяют лестницы и отдельные участки, зелёная отмечает выход. Между лампами остаются тёмные промежутки. Свечение светильников добавляет существующий bloom.

- `ambient` - фоновое освещение, RGB от 0 до 1. Сейчас `[0.18, 0.21, 0.28]`. Увеличение значений делает тёмные места светлее.
- `presets` - стили `cold`, `warm`, `exit`. У каждого есть `color` (RGB от 0 до 1), `intensity` (яркость) и `radius` (дальность в мировых единицах).
- `lamps` - список светильников, максимум 128. У каждого есть `style` и положение.
- `shadow_resolution` - размер каждой грани карты теней: 64, 128 или 256. Сейчас 128. Увеличение до 256 сглаживает ступенчатость, но требует в четыре раза больше памяти для атласа.

Лампа в клетке лабиринта:

```json
{"node": [0, 19, 1], "style": "cold"}
```

Координаты - `[этаж, строка, столбец]`, начиная с нуля. Клетка должна быть проходом `.`. Светильник автоматически ставится под потолком этого этажа.

Для лестничных площадок можно задать мировые координаты источника:

```json
{"position": [-36.0, 3.06, -9.0], "style": "warm"}
```

Корпус и светящаяся панель появляются чуть выше источника. Это декорации, они не меняют столкновения игрока.

Свет плавно затухает с расстоянием. Стены, ступени, корпуса светильников и межэтажное перекрытие отбрасывают тени. Тени рассчитываются один раз при загрузке статичного уровня. После правки позиций ламп или геометрии нужно перезапустить игру. Для движущихся объектов и будущей модели игрока тени пока не рассчитываются.

Удаление раздела `lighting` возвращает прежнее освещение граней. Глобальный холодный оттенок и bloom регулируются отдельно в `config/settings.py`.

Проверки:

```powershell
.\.venv\Scripts\python.exe tools\check_lighting.py
.\.venv\Scripts\python.exe tools\check_maze.py
```

Сравнение - `artifacts/lighting-before.png` и `artifacts/lighting-after.png`. Отчёт - `artifacts/lighting-check.json`. Кадры лестницы и выхода - `artifacts/maze-stairs.png` и `artifacts/maze-exit.png`.
