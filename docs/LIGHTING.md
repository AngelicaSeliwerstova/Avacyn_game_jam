# Свет на карте

В `resources/levels/maze.json`, в разделе `lighting`, стоят 102 лампы лабиринта. Холодные освещают проходы, тёплые выделяют лестницы и отдельные участки, зелёная отмечает выход. Раздел `basement` добавляет 225 ламп сеткой на потолке пустого подвала и две лампы на его лестнице. Всего на карте 329 источников. Свечение светильников добавляет существующий bloom.

- `ambient` - фоновое освещение, RGB от 0 до 1. Сейчас `[0.18, 0.21, 0.28]`. Увеличение значений делает тёмные места светлее.
- `presets` - стили `cold`, `warm`, `exit`. У каждого есть `color` (RGB от 0 до 1), `intensity` (яркость) и `radius` (дальность в мировых единицах).
- `lamps` - список светильников. У каждого есть `style` и положение. Общий бюджет уровня, включая созданные по данным сетки, - до 512 источников.
- `shadow_resolution` - размер каждой грани карты теней: 64, 128 или 256. Сейчас 128. Увеличение до 256 сглаживает ступенчатость, но требует в четыре раза больше памяти для атласа.

Лампа в клетке лабиринта:

```json
{"node": [0, 19, 1], "style": "cold"}
```

Координаты - `[этаж, строка, столбец]`, начиная с нуля. Клетка должна быть проходом `.`. Светильник автоматически ставится под потолком этого этажа.

Для лестничных площадок можно задать мировые координаты источника:

```json
{"position": [-36.0, 3.06, -9.0], "style": "warm"}
```

Корпус и светящаяся панель появляются чуть выше источника. Это декорации, они не меняют столкновения игрока.

Свет плавно затухает с расстоянием. Стены, ступени, корпуса светильников и межэтажное перекрытие отбрасывают тени. Тени рассчитываются один раз при загрузке статичного уровня. После правки позиций ламп или геометрии нужно перезапустить игру. Для движущихся объектов и будущей модели игрока тени пока не рассчитываются.

Положение, радиус, цвет и яркость ламп хранятся в GPU-текстуре данных. Это позволяет использовать сотни источников без большого массива uniform-переменных. Раскладка атласа теней учитывает число ламп, разрешение и допустимый размер текстуры GPU. При увеличении числа источников растёт память атласа теней; локальные списки уменьшают работу при отрисовке, но не размер этого атласа.

## Мерцание

Сейчас мерцают четыре лампы лабиринта, включая лампу у старта, и три лампы подвала. Остальные 322 светят постоянно. `LIGHT_FLICKER_ENABLED = False` в `config/settings.py` отключает анимацию всех источников.

Для отдельной лампы добавьте `flicker`:

```json
{
  "node": [0, 19, 1],
  "style": "cold",
  "flicker": {"interval": 8.0, "duration": 0.7, "minimum": 0.3, "seed": 19}
}
```

- `interval` - время между короткими сбоями, в секундах.
- `duration` - длительность сбоя, меньше `interval`. Внутри него происходят два плавных провала яркости.
- `minimum` - минимальная доля исходной яркости: 0 выключает источник в самой глубокой точке, 1 сохраняет постоянный свет.
- `seed` - целое число, сдвигающее момент сбоя относительно других ламп.

`flicker` можно задать и в стиле `presets`. Поле конкретной лампы переопределяет стиль, а `"flicker": null` отключает эффект для неё.

В подвале `basement.flickering_lamps` задаёт номера ламп сетки, начиная с нуля: `row * lamp_columns + column`. Сейчас это `[39, 151, 217]`; лампа 151 находится рядом с коробками. Общие параметры лежат в `basement.flicker`, а фаза дополнительно сдвигается номером лампы.

CPU вычисляет только коэффициенты яркости выбранных ламп. При изменении коэффициента обновляется одна строка GPU-текстуры данных, тот же коэффициент меняет свечение привязанной панели. Само освещение поверхностей по-прежнему считает шейдер. Положение и радиус источника, локальная сетка света и карты теней остаются прежними; повторного запекания нет. Анимация обновляется через `Renderer.update(delta_time)` в игровом цикле, а повторный вызов `render` сам по себе время не двигает.

Удаление раздела `lighting` возвращает прежнее освещение граней. Глобальный холодный оттенок и bloom регулируются отдельно в `config/settings.py`.

Проверки:

```powershell
.\.venv\Scripts\python.exe tools\check_lighting.py
.\.venv\Scripts\python.exe tools\check_shadow_acne.py
.\.venv\Scripts\python.exe tools\check_maze.py
.\.venv\Scripts\python.exe tools\check_atmosphere.py
```

Сравнение - `artifacts/lighting-before.png` и `artifacts/lighting-after.png`. Отчёт - `artifacts/lighting-check.json`. Кадры лестницы и выхода - `artifacts/maze-stairs.png` и `artifacts/maze-exit.png`.

`check_shadow_acne.py` проверяет ровные стены под скользящим светом: четыре ориентации стены, две высоты лампы, три разрешения теней и движение камеры. Внутренняя часть стены сравнивается с эталоном без препятствий. Сглаживание теней учитывает глубину плоскости в каждой соседней точке, чтобы стена не затеняла сама себя полосами. Кадр проверки - `artifacts/shadow-wall-actual.png`, отчёт - `artifacts/shadow-acne-check.json`.
