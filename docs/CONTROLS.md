# Запуск и управление

Из папки проекта, в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Окно, разрешение и графика настраиваются в `config/settings.py`, клавиши - в `config/controls.py`. После изменения настроек перезапустите игру.

| Клавиша | Действие |
| --- | --- |
| WASD, мышь | Ходьба и обзор |
| Shift | Бег |
| Пробел | Прыжок |
| Ctrl | Присед при удержании |
| ПКМ | Зум при удержании |
| Q | Смотреть назад через плечо при удержании |
| E | Осмотр, подбор ключа, открытие двери |
| F | Фонарик, изначально выключен |
| F3 | Панель разработчика |
| F5 | Следующий цветовой пресет |
| F11 | Полный экран |
| Esc | Освободить курсор; ЛКМ по окну возвращает управление |

Присед меняется только на земле. Под низким потолком персонаж не встаёт, пока не появится место. Esc и потеря фокуса отключают управление, но не ставят игру на паузу.

При удержании Q камера и направление осмотра разворачиваются назад; направление движения персонажа сохраняется. После отпускания Q обычный ракурс возвращается.

На карте `maze` впереди справа от старта лежит отдельный ключ от подвала. Его дверь находится слева. Ключи подбираются на E и остаются в инвентаре. Сохранения пока нет: после перезапуска двери снова заперты.

Цель игры - сбежать на балкон второго этажа. На первом этаже найдите `Upper-floor key`: он открывает обе лестницы. На втором найдите `Balcony key` и откройте дверь балкона. Дойдите до середины балкона, чтобы победить. Текущая задача показана в HUD. Подвал необязателен: открыв его дверь, вы выпускаете улитку.

Касание улитки означает поражение: сцена замирает, курсор освобождается. На экране «Ты проиграл» можно выбрать пункт мышью, нажать Enter или R для новой игры, Esc для выхода. Новая игра сбрасывает весь уровень, ключи и врагов.

Экран «Ты выбрался» управляется так же. Половина потолочных ламп погашена; фонарик включается на F.

На каждом этаже есть три низких лаза с металлической окантовкой. В них нужно заранее присесть на Ctrl. Улитка проходит свободно: её скорость 1.95 м/с, а игрока в приседе - 1.7 м/с. Лазы сокращают длинные обходы, поэтому могут помочь и преследователю.

## Что показывает F3

`FPS` и `FRAME` учитывают весь кадр, включая VSync и ограничитель. `CPU UPDATE` и `DRAW` показывают время работы на CPU, а не отдельный замер видеокарты.

`FEET XYZ` - положение ног, `CAM XYZ` - камеры; Y направлен вверх. `MOVE`, `GROUND`, `VY` и `CROUCH/STAND` показывают движение, опору, вертикальную скорость и позу. Положение хранит `CharacterBody`; камера третьего лица следует за игроком.

`SCENE` - треугольники и вызовы цветового прохода, `ZPASS` - прохода глубины. Они не включают HUD, постобработку и карты теней. `LIGHTS` - лампы уровня, `local <= N` - самый длинный список ламп для участка карты, `SPOT` - включённые подвижные источники. `F: ON/OFF` относится к фонарику.

Параметры панели находятся в `DEBUG_*`. Для сравнения производительности учитывайте `VSYNC`, `FPS_LIMIT` и внутреннее разрешение `RENDER_SIZE`.

`ENEMY` показывает состояние улитки (`CHASE` или `WAITING`), расстояние и число оставшихся точек маршрута `PATH`. `FULL` означает путь до игрока, `PARTIAL` - только до ближайшей доступной точки. В F3 оставшийся маршрут показан красной линией, видимой через стены. Линия начинается у улитки и обновляется вместе с её движением и пересчётом пути. При выключенном F3 она не рисуется.

Улитка начинает в подвале и всегда знает, где игрок. Закрытая дверь может задержать её, но потерять игрока из виду она не может. При касании игрок проигрывает; через стену или с другого этажа поймать нельзя.

Скорость ходьбы - 3.5 м/с, бега - 6.5 м/с, в приседе - 1.7 м/с. Настройки: `MOVE_SPEED`, `SPRINT_SPEED`, `CROUCH_SPEED`.
