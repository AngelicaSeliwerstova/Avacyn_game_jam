# Запуск и управление

Из папки проекта, в PowerShell:

Используйте Python 3.12 для создания окружения (на нём проверены зависимости).

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если `.venv` уже подготовлена, повторная установка не нужна. Для тестирования
союзника сразу в трёхэтажной больнице:

```powershell
.\.venv\Scripts\python.exe main.py --level start --debug
```

Союзник уже следует за игроком. Открывайте двери на E; F3 переключает панель
диагностики и линии маршрутов. `--level peaceful` запускает мирное начало;
`--creator` можно сочетать с выбором карты и диагностикой.

Окно, разрешение и графика настраиваются в `config/settings.py`, клавиши - в `config/controls.py`. После изменения настроек перезапустите игру.

| Клавиша | Действие |
| --- | --- |
| WASD, мышь | Ходьба и обзор |
| Shift | Бег |
| Пробел | Прыжок |
| Ctrl | Присед при удержании |
| ПКМ | Зум при удержании |
| Q | Смотреть назад через плечо при удержании |
| E | В игре — действие с видимым объектом; в Creator — выбрать камеру / завершить её редактирование |
| Tab | Открыть / закрыть инвентарь |
| F | Фонарик, изначально выключен |
| F3 | Панель разработчика (при запуске с `--debug`) |
| F5 | Следующий цветовой пресет |
| F4 | Переключить мерцание наведённой лампы (Creator) |
| F6 | Режим Creator: свободная камера и расстановка объектов |
| F7 | Поставить камеру на стену и сохранить (Creator) |
| F8 | Сменить материал блока или цвет наведённой лампы (Creator) |
| F9 | Поставить блок на поверхность (Creator) |
| F10 | Поставить лампу на поверхность (Creator) |
| F12 | Пересчитать тени после изменений (Creator) |
| Delete | Удалить предмет, на который наведена камера (Creator) |
| F11 | Полный экран |
| Esc | Освободить курсор; ЛКМ по окну возвращает управление |

Присед меняется только на земле. Под низким потолком персонаж не встаёт, пока не появится место. Esc и потеря фокуса отключают управление, но не ставят игру на паузу.
На ступенях высота камеры меняется плавно при подъёме и спуске. Параметр
`STAIR_CAMERA_SMOOTHING` задаёт скорость догоняния: меньше — мягче, больше — быстрее.

Стартовая карта `peaceful` — мирная копия первого этажа. Игрок начинает у главного
входа в южном холле. Пройдите в кабинет врача слева, в дальнем конце коридора:
в глубине комнаты поговорите с человеком на E и завершите диалог, чтобы загрузить
трёхэтажную больницу `start`. Игрок остаётся в том же
кабинете, инвентарь сохраняется. В мирной версии проход на лестницу закрыт;
после перехода лестница соединяет все три этажа.
Двери открываются и закрываются на E без ключей. Подсказка меняется между
«Открыть» и «Закрыть». Во время движения двери повторное действие недоступно;
если полотно упирается в игрока, оно ждёт, пока он отойдёт.
Врагов и сюжетных задач пока нет.
После сюжетного перехода союзника можно видеть и сопровождать, но игрок проходит
сквозь него, чтобы он не блокировал движение в узких коридорах и на лестницах.

## Инвентарь

Tab открывает инвентарь поверх игры; повторное нажатие Tab или Esc закрывает его.
В ячейках показаны найденные предметы, названия и количество. Ключи после подбора
появляются здесь автоматически. Если предметов больше шести, переключайте страницы
стрелками ←/→ или колесом мыши. Пустой инвентарь показывает «Пока пусто».

Пока инвентарь открыт, игровой мир стоит на паузе: движение, двери и враги не
обновляются. Игровые действия не срабатывают через окно. После закрытия возвращается
предыдущее состояние захвата мыши, если окно игры сохраняет фокус.

## Creator

Запуск сразу в редакторе: `python main.py --creator`. F6 переключает редактор
и обычный режим игры. В Creator WASD и мышь управляют свободным полётом,
Space/Ctrl меняют высоту, Shift ускоряет движение.

Наведите прицел на стену и нажмите F7 для установки камеры. E включает её
предпросмотр; WASD поворачивают выбранную камеру, повторное E сохраняет угол.
F9 ставит блок на поверхность. F8 меняет материал блока или цвет наведённой
лампы. F10 ставит лампу, F4 меняет её мерцание. Delete удаляет наведённый объект
редактора. F12 пересчитывает тени.

Для каждой карты камеры, блоки и лампы сохраняются в собственные файлы:
`<имя>_cameras.json`, `<имя>_objects.json`, `<имя>_lights.json` в `resources/levels/`.
Если камеры ещё не установлены, работает обычная камера игрока.

## Диагностика

В мирной больнице в дальнем кабинете: E — начать разговор с человеком,
E / Enter или кнопка на экране — следующая реплика. После разговора вы вместе
попадаете в трёхэтажную больницу; союзник следует за игроком.

Запуск с диагностикой: `python main.py --debug` (можно вместе с `--creator`).
Без флага панель, F3, замеры и запись логов отключены.
В режиме `--debug` F3 скрывает и показывает панель; запись логов продолжает работать.
Каждый кадр ниже 45 FPS записывается в `logs/performance-<дата-время>.jsonl`.
В записи есть точное время UTC, время от запуска, FPS, координаты игрока/камеры,
состояние сцены, количество объектов и коллайдеров, статистика света и draw calls.
Замеры отдельно показывают ожидание лимита FPS, обработку событий/ввода, обновление
игрока, каждую игровую систему (например, `system_1_EnemySystem`), этапы рендера,
HUD и вывод кадра. `largest_stage` указывает самый долгий измеренный этап; для
систем это конкретный класс, а не их общий интервал. `systems_actors_session`
содержит общий интервал систем и включает их отдельные замеры — эти значения
перекрываются, их нельзя складывать. Также записываются `delta_time_s` и число
сборок мусора Python за кадр.

Времена — замеры на CPU; ожидание GPU может учитываться в отрисовке или выводе
кадра. Они помогают локализовать задержку, но сами по себе не доказывают её
причину. Файл буферизуется и сохраняется при выходе.

Панель показывает FPS, время кадра, координаты игрока и камеры, состояние движения,
число источников света и статистику отрисовки. F11 переключает полный экран.
`RENDER_SIZE` задаёт внутреннее разрешение картинки, `WINDOW_SIZE` — размер окна.
Картинка масштабируется до максимального размера в окне с сохранением пропорций,
включая нецелый масштаб. При `640×480` в окне `1536×864` она занимает `1152×864`.
F11 разворачивает игру на весь экран; повышать внутреннее разрешение для этого не нужно.

Подробнее о геометрии карт и переходах — в [LEVELS.md](LEVELS.md).
