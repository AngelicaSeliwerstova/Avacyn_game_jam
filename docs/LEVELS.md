# Карты геймджема

Стартовая карта — `resources/levels/start.json`: первый этаж больницы по плану
43×29 метров. `layout: "hospital_first_floor"` подключает сборку геометрии
из `game/levels/hospital.py`. Дополнительные `boxes`, `objects` и данные Creator
по-прежнему загружаются из файлов карты.

Север занимает ряд из шести кабинетов слева направо: кабинет врача, процедурная,
смотровая, палата, склад и вторая палата. Между ними и южными помещениями проходит
длинный коридор с боковым входом справа. Внизу слева — двухсветный лестничный зал
с отдельной гостиной, по центру — компактная охрана, справа — отдельная регистрация.
Открытый холл огибает служебные комнаты и соединяется с коридором в центральной части.
В холле и коридоре стоят кожаные диваны, столики и растения; в кабинетах — кровати,
шкафы, рабочие места, радиаторы и медицинские тележки. Игрок появляется
у главного входа. Двери открываются на E без ключей; у кабинетов есть таблички,
названия которых можно прочитать через взаимодействие. Игровая камера осталась
прежней: вид сверху используется только для обзорного изображения плана.

Мебель и декор собраны в `game/levels/hospital_props.py`. Крупные предметы имеют
коллайдеры, мелкие детали и листья не мешают движению. `hospital_floor` использует
существующую текстуру потёртой плитки с более крупным масштабом, без шахматного рисунка.

Винтовая лестница задаётся в `game/levels/spiral.py`: центр `(-13, 4)` по XZ,
внутренний радиус 1,55 м, наружный — 4,2 м, ширина — 2,65 м. 36 ступеней
с подъёмом около 13,3 см делают полный оборот и выводят на галерею высотой 4,8 м.
Ступени и ограждения имеют коллайдеры. Вход в марш находится с юга зала,
верхний выход идёт по касательной на восток. Колодец открыт до пола первого этажа.
Полный второй этаж пока не построен: сверху доступна только галерея лестничного зала.
План не содержит врагов, ключей, сюжетных задач и переходов в другие локации.

Начальная карта выбирается через `LEVEL_NAME = "start"` в `config/settings.py`.
Изменения JSON подхватываются после перезапуска. Камеры, блоки и лампы Creator
сохраняются сразу, отдельно для каждой карты.

## Новая локация

Создайте `resources/levels/location_2.json`. Регистрация в коде не требуется.
Имена карт могут содержать маленькие латинские буквы, цифры, `_` и `-`.

Минимальный файл:

```json
{
  "floor_size": [24.0, 24.0],
  "floor_material": "concrete",
  "room_height": 3.3,
  "spawn_position": [0.0, 1.6, 6.0],
  "spawn_target": [0.0, 1.6, 5.0],
  "boxes": [],
  "objects": []
}
```

`spawn_position` и `spawn_target` задают положение глаз и направление взгляда
при входе в локацию. X и Z лежат в плоскости пола, Y направлена вверх.
`floor_size` задаёт размеры пола, центрированного в `(0, 0)`.
`base_height` меняет высоту пола, по умолчанию она равна нулю.
`room_height` нужен Creator для размещения ламп; сам потолок нужно добавить в `boxes`.

В `boxes` задаются блоки с `position` (центр), `size`, `material` и необязательным
`yaw_degrees`. Они участвуют в столкновениях и отбрасывают тени. Названия материалов
находятся в `MATERIAL_TEXTURES` в `config/settings.py`.

`lighting` принимает `ambient` и список `lights`: для каждого света задаются
`position`, `color`, `intensity`, `radius` и необязательный `flicker`.
По умолчанию используется равномерное фоновое освещение без ламп.
Снег включается только при `snow_enabled: true` и глобальном `SNOW_ENABLED`.

## Creator

Запустите `python main.py --creator` или нажмите F6 во время игры. Стены и потолки
дают поверхности для установки камер, блоков и ламп.

Для `start` редактор создаёт:

- `start_cameras.json` — фиксированные камеры;
- `start_objects.json` — добавленные блоки;
- `start_lights.json` — лампы, их цвет и мерцание.

Если камер нет, используется обычная камера игрока. Для других карт имена
файлов строятся из имени локации. Основная геометрия из `boxes` редактируется
в JSON; удаление через Creator относится к добавленным в редакторе объектам.

## Переход между картами

В `objects` первой карты добавьте область выхода:

```json
{
  "id": "next_location_exit",
  "type": "exit",
  "position": [6.0, 0.0, -6.0],
  "radius": 1.2,
  "required_keys": [],
  "next_level": "location_2"
}
```

`position` выхода задаётся на уровне ног игрока. Переход срабатывает при входе
в радиус, если собраны все ключи из `required_keys`. Без `next_level` выход
показывает финальный экран победы. Сейчас в `start` выходов нет.

В `objects` также поддерживаются `key`, `door` и `enemy`, с явным `position`.
Ключу нужны `id`, `key_id` и необязательное `name`. Двери нужен `id`; без
`key_id` она открывается свободно на E, с `key_id` требует соответствующий ключ.
Размер проёма задают `opening_width` и `wall_height`, размер полотна — `width`,
`height` и `thickness`. Враг получает `id` и необязательные `settings`.

При смене карты сохраняются инвентарь, состояние фонарика, сюжетные флаги
`Campaign.progress.flags` и множество пройденных карт `completed_levels`.
Ключи имеют общие идентификаторы для всего прохождения. Новая сцена получает
собственную геометрию, свет, камеры, врагов и точку старта. Во время загрузки
показывается чёрный кадр, окно остаётся открытым.

Прогресс хранится в памяти. «Заново» начинает прохождение с `LEVEL_NAME`.
При повторном посещении карты её двери, предметы и враги создаются заново.
В режиме Creator выходы не срабатывают.
