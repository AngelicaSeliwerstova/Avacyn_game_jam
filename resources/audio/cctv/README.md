# Звуки видеорегистратора

`button_click.wav`, `correct.wav`, `incorrect.wav`, `static.wav` и `impact.wav`
процедурно созданы для проекта скриптом `tools/prepare_cctv_assets.py`.
Формат: моно, PCM 16 бит, 44100 Гц. Сторонних мелодий и записей в этих файлах нет.

Шаги в начале записи используют уже включённый CC0 файл больничных шагов;
его источник и обработка указаны в `../hospital/sources.json`.
Звуки и субтитры настраиваются в `resources/puzzles/cctv/archive.json`.

`voices/recording_01.wav` — `recording_11.wav` содержат полную ссору из актуального
сценария: офлайн-синтез Microsoft Irina Desktop, разные высота и темп для подруги
и неизвестной девушки. Это синтез речи, не актёрская запись. Игра воспроизводит
готовые WAV и не требует установленного TTS. Генерация и замер длительностей:
`powershell -File tools/prepare_campaign_voices.ps1`. После замены WAV актёрской
записью запустите `python tools/time_campaign_voices.py`.

Речевая озвучка отключена по просьбе пользователя: `speech_enabled: false`
в определении архива. WAV остаются исходными ресурсами, но не воспроизводятся.
Не включать синтезированную речь без прямой просьбы пользователя.
