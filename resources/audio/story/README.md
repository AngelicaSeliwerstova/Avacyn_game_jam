# Сценарные звуки

Все четыре WAV созданы процедурно для этого проекта скриптом
`tools/prepare_act1_assets.py`; сторонние записи и мелодии не использованы.

- `music_box.wav` — оригинальная мелодия шкатулки: затухающие тоны с обертонами.
- `clock_tick.wav` — короткий синтезированный удар часов.
- `tv_static.wav` — детерминированный отфильтрованный шум телевизора.
- `lock_click.wav` — синтезированный щелчок замка.

Формат: моно, PCM 16 бит, 44100 Гц. Положение, громкость и сюжетные условия
задаются в `resources/story/hospital/acts/act1/act.json` → `audio_sources`.
Голоса девочки и матери используют отдельные профили синтезированных диалоговых
сигналов из `campaign.json`, с титрами воспоминания.

Тем же скриптом созданы текстуры часов, телевизионных помех, вспышки воспоминания
и детского рисунка в `resources/textures/story/`. Для воспроизведения ресурсов:

```powershell
.\.venv\Scripts\python.exe tools/prepare_act1_assets.py
```
