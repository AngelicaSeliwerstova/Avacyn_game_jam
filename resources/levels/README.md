# Карты геймджема

`peaceful.json` — мирная версия общей трёхэтажной больницы, начальная локация.
До перехода подъём сюжетно ограничен; расположение стен и мебели совпадает с `start`.
Внутри дальнего кабинета
врача происходит переход в `start.json` — трёхэтажную больницу с винтовой лестницей.
Имя файла без `.json` используется
в `LEVEL_NAME` и `next_level`.

Creator сохраняет данные каждой локации отдельно: `<имя>_cameras.json`,
`<имя>_objects.json`, `<имя>_lights.json`. Эти файлы создаются при редактировании.

В `peaceful`, `start`, `act1` и `act2` уже расставлены 174 фиксированных ракурса:
коридоры, кабинеты, палаты, регистратура, охрана и оба витка лестницы.
Общая постановка сохраняется при превращении больницы; каждый файл камер можно
дальше независимо редактировать через F6. Исходная расстановка описана в
`tools/prepare_hospital_cameras.py`; запуск с `--write` **перезаписывает все четыре
файла камер**, включая последующие правки Creator.

Проверка покрытия по геометрии и снимки выбранных игровых ракурсов:

```powershell
.\.venv\Scripts\python.exe tools/camera_preview.py --check --level start
.\.venv\Scripts\python.exe tools/camera_preview.py --level start
```

Результаты находятся в `artifacts/camera-qa/`: отчёт покрытия, отдельные кадры
и контактный лист. Снимки включают героиню и используют реальный выбор камеры;
для обзора интерьеров двери на время предпросмотра открываются.
