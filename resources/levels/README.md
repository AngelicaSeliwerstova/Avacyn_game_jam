# Карты

- `corridor.tmx` - небольшой коридор для Tiled.
- `maze.json` - фиксированный двухэтажный лабиринт. При каждом запуске разметка одинаковая.
- Выбор карты находится в `config/settings.py`: `LEVEL_NAME = "maze"`. Прежние `stairs`, `corridor`, `demo` доступны там же.

Большой уровень занимает 81x75 мировых единиц. В нём два лабиринта по 21x21 клетке, две лестничные клетки и балкон выхода. Коридоры шириной 3 единицы; полы находятся на высоте 0 и 3.6. Между этажами есть сплошное перекрытие. Лестницы имеют по 16 ступеней и ограждения.

В `maze.json`:

- `floors[0]`, `floors[1]` - строки первого и второго этажей. `#` означает стену, `.` означает проход. Размеры строк обоих этажей должны совпадать.
- `cell_size` - размер клетки в мире.
- `floor_height`, `wall_height`, `slab_thickness` - высота этажа, стен и толщина перекрытия. Стены вместе с перекрытием должны заполнять высоту этажа.
- `floor_materials`, `wall_materials` - материалы полов и стен из `MATERIAL_TEXTURES`.
- `stairs` - две связи между этажами. Клетки дверей на западной или восточной границе должны оставаться открытыми.
- `stair_steps`, `stair_run`, `stair_width`, `wing_width` - ступени и размеры лестничных клеток.
- `spawn`, `exit` - `[этаж, строка, столбец]`, нумерация с нуля. Выход находится на северной границе второго этажа и ведёт на балкон.

Во время игры подпись показывает текущий этаж. Выход отмечен ржавой рамой; на балконе появляется `EXIT FOUND`. После этого можно продолжить исследование. Снег внутри здания отключён.

Проверка после правки карты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tools\check_maze.py
```

План этажей сохраняется в `artifacts/maze-plan.png`, кадры - в `artifacts/maze-*.png`, отчёт - в `artifacts/maze-check.json`.
