# Сухие деревья

Материалы `dead_bark` (иссохшая кора) и `dead_wood` (обнажённая древесина).
Игровые варианты: `dead_bark_128.png`, `dead_bark_256.png`,
`dead_wood_128.png`, `dead_wood_256.png`. Оригиналы сохранены рядом как `*_source.png`.
Встроенный image_gen сгенерировал оригиналы; игровые размеры получены обычным
уменьшением без дополнительной генерации. Размер повторения: 1,2 м.

В Creator добавлены пресеты «Иссохшее дерево», «Иссохшее деревце» и
«Сломанный сухой ствол». На готовые этажи они автоматически не расставляются.
