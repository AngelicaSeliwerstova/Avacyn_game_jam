# Текстуры окружения

Файлы разложены по изображению: исходные названия часто не совпадали с содержимым. Все 13 добавленных PNG сохранены без изменения пикселей.

| Материал | Файлы | Где используется |
| --- | --- | --- |
| `asphalt` | `floors/asphalt_128.png`, `asphalt_256.png` | Пол сцены с лестницей |
| `dirty_tiles` | `floors/dirty_tiles_128.png`, `dirty_tiles_256.png` | Пол коридора |
| `wood` | `floors/rotten_wood_128.png`, `rotten_wood_256.png` | Верхняя площадка и пол демо |
| `concrete` | `walls/cracked_concrete_128.png`, `cracked_concrete_256.png` | Ступени |
| `plaster` | `walls/dirty_plaster_128.png` | Средняя часть коридора |
| `hospital_tiles` | `walls/hospital_tiles_128.png` | Стены у старта коридора |
| `brick` | `walls/red_brick_128.png` | Стены у поворота коридора |
| `rust` | `metals/rust_128.png`, `rust_256.png` | Куб в демо |

- `MATERIAL_TEXTURES` в `config/settings.py` связывает имя материала с PNG и размером повторения в мире. Пути считаются от этой папки.
- `TEXTURE_RESOLUTION = 128` выбирает небольшие версии. Значение 256 включает большие там, где они есть; кирпич, штукатурка и больничная плитка остаются 128.
- Параметры `STAIRS_*_MATERIAL`, `CORRIDOR_*_MATERIAL` и `DEMO_*_MATERIAL` назначают материалы сценам. Стены коридора разделены на три участка от старта к повороту.
- `Box.material` задаёт материал отдельного блока, `Level.floor_material` задаёт материал пола.
- `FLOOR_TEXTURE` и `WALL_TEXTURE` служат запасными текстурами для объектов без назначенного материала. `None` отключает текстуры соответствующего типа поверхности.
- Изображения повторяются в мировых координатах. По умолчанию одна картинка занимает 2x2 мировые единицы.
- Вблизи используется nearest, при уменьшении - трилинейная фильтрация с mipmaps. Уменьшенные версии генерируются при загрузке; одинаковый PNG загружается на GPU один раз.
- `TEXTURE_ANISOTROPY` помогает на наклонных поверхностях. Значение 1 отключает эффект.
- `TEXTURE_MIPMAPS = False` включает nearest без mipmaps для сравнения; `TEXTURES_ENABLED = False` возвращает цветные поверхности.
- `samples/` содержит первоначальные тестовые изображения из `tools/create_test_textures.py`.
- Настройки применяются после перезапуска. Используются непрозрачные PNG.
