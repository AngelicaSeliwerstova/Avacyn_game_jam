# Текстуры окружения

- `floors/concrete.png` - тестовая текстура пола, 128x128.
- `walls/plaster.png` - тестовая текстура блоков и стен, 128x128.
- Изображения созданы скриптом `tools/create_test_textures.py`. Скрипт сохраняет уже существующие файлы.
- Для замены положи свой непрозрачный PNG и укажи его путь в `FLOOR_TEXTURE` или `WALL_TEXTURE` в `config/settings.py`. Пути считаются от этой папки.
- `FLOOR_TEXTURE_WORLD_SIZE` и `WALL_TEXTURE_WORLD_SIZE` задают размер одного повторения в мире. Сейчас картинка занимает 2x2 мировые единицы.
- Грани блоков получают координаты текстуры из мирового положения. Рисунок сохраняет масштаб на блоках разного размера.
- Вблизи используется nearest, при уменьшении - трилинейная фильтрация с mipmaps. Уменьшенные версии генерируются один раз при загрузке PNG.
- `TEXTURE_ANISOTROPY` помогает на наклонных поверхностях. Значение ограничивается возможностями видеокарты, 1 отключает эффект.
- `TEXTURE_MIPMAPS = False` включает nearest без mipmaps для сравнения.
- `TEXTURES_ENABLED = False` возвращает цветные поверхности. `None` вместо пути отключает отдельную текстуру.
- Настройки применяются после перезапуска. Прозрачные материалы пока не поддерживаются.
