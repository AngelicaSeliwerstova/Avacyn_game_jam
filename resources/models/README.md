# Модели

- `player/player.glb` - место для будущей модели персонажа в формате GLB.
- `PLAYER_MODEL = None` в `config/settings.py` - модель пока не назначена.
- `PLAYER_MODEL_OFFSET`, `PLAYER_MODEL_ROTATION`, `PLAYER_MODEL_SCALE` - локальное смещение, поворот в градусах и масштаб будущей модели.
- Сущность стоит началом координат между ногами; её направление вперёд -Z, вверх +Y.
- Сейчас хранится только описание модели. Чтение GLB, материалы и анимации ещё не реализованы.
