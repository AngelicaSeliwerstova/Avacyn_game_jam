# Модели

- `player/girl_chestnut_black_stockings.glb` — текущая модель игрока с каштановыми волосами и чёрными чулками. Для корректной отрисовки прозрачные участки материалов переведены в маску; исходный файл пользователя не изменён.
- Путь модели задаётся в `config/settings.py` относительно `resources/models` через `PLAYER_MODEL`.
- `PLAYER_MODEL_OFFSET`, `PLAYER_MODEL_ROTATION`, `PLAYER_MODEL_SCALE` настраивают локальное положение, поворот в градусах и размер.
- `PLAYER_CAMERA_DISTANCE` и `PLAYER_CAMERA_HEIGHT` настраивают камеру третьего лица.
- Сущность стоит началом координат между ногами; её направление вперёд -Z, вверх +Y.
- Экспортируйте модели из Blender как glTF 2.0 Binary (`.glb`) с включёнными анимациями и встроенными текстурами.
- Загрузчик поддерживает треугольные меши, встроенные изображения PNG, скелетную анимацию с интерполяцией `LINEAR` или `STEP`.
- В каталоге `player` также остаётся история с альтернативной моделью `player.glb`, если нужно сравнить ранние варианты или вернуть старый актив по окончании синхронизации.
