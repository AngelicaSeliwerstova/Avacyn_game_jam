# Модели

- `props/friend_rest.glb` — неподвижная лежащая подруга для финального акта,
  подготовлена из пользовательского `friend.glb`. Служебная сфера исключена,
  исходные текстуры перенесены из emission в albedo для больничного освещения.
  Оригинал не изменён. Повторный экспорт в Blender:
  `blender --background --python tools/prepare_friend_model.py`.

- `props/pumpkin.glb` — тыква из пользовательского `pumpkin_1.blend` в корне проекта.
  Исходник сохранён; при экспорте модификаторы применяются к копии геометрии,
  начало координат ставится по центру основания, диаметр нормализуется до 1 м.
  Повторный экспорт: `blender --background --python tools/prepare_pumpkin_model.py`.
  Расстановка задана в `game/levels/hospital_pumpkins.py`: 7 экземпляров на первом
  этаже и 9 на втором, в мирной и изменённой версиях больницы. Размеры и повороты
  различаются; тыквы стоят в стороне от дверей и лестницы.

- `doctor/girl_white.glb` — беловолосая девочка для врача/союзника в обеих версиях
  больницы. Создана из пользовательского `Девочка_ходьба_белая.glb`; оригинал сохранён.
  Активный цикл ходьбы — `Girl Walk In Place - Straighter Stance 24f`.
  Материалы с `BLEND` подготовлены как `MASK`, чтобы волосы и одежда не просвечивали.
  Остальные анимации и встроенные текстуры сохранены в файле.
- Модель врача задаётся через `DOCTOR_MODEL`, `DOCTOR_MODEL_OFFSET`,
  `DOCTOR_MODEL_ROTATION`, `DOCTOR_MODEL_SCALE` в `config/settings.py`.
  Для союзника в JSON-карте используется `"appearance": "doctor"`.
  Подготовку можно повторить: `python tools/prepare_doctor_model.py`.

- `player/girl_chestnut_black_stockings.glb` — текущая модель игрока с каштановыми волосами и чёрными чулками. Для корректной отрисовки прозрачные участки материалов переведены в маску; исходный файл пользователя не изменён.
- Путь модели задаётся в `config/settings.py` относительно `resources/models` через `PLAYER_MODEL`.
- `PLAYER_MODEL_OFFSET`, `PLAYER_MODEL_ROTATION`, `PLAYER_MODEL_SCALE` настраивают локальное положение, поворот в градусах и размер.
- `PLAYER_CAMERA_DISTANCE` и `PLAYER_CAMERA_HEIGHT` настраивают камеру третьего лица.
- Сущность стоит началом координат между ногами; её направление вперёд -Z, вверх +Y.
- Экспортируйте модели из Blender как glTF 2.0 Binary (`.glb`) с включёнными анимациями и встроенными текстурами.
- Загрузчик поддерживает треугольные меши, встроенные изображения PNG, скелетную анимацию с интерполяцией `LINEAR` или `STEP`.
- В каталоге `player` также остаётся история с альтернативной моделью `player.glb`, если нужно сравнить ранние варианты или вернуть старый актив по окончании синхронизации.
