# Модели

- `player/player.glb` - модель девочки с текстурами, скелетом и анимациями ходьбы.
- `PLAYER_MODEL = "player/player.glb"` в `config/settings.py` - путь модели игрока.
- `PLAYER_MODEL_OFFSET`, `PLAYER_MODEL_ROTATION`, `PLAYER_MODEL_SCALE` - локальное смещение, поворот в градусах и масштаб будущей модели.
- Сущность стоит началом координат между ногами; её направление вперёд -Z, вверх +Y.
- В GLB есть анимация `Girl Walk In Place - Straighter Stance 24f` (выбранный вариант ходьбы).
- Чтение GLB, материалы и скелетная анимация в игровом движке ещё не реализованы. Путь модели уже задан, но для её появления на экране нужен загрузчик и отображение персонажа.
