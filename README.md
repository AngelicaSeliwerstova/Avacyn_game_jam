# Структура проекта

```text
gamek/
|- main.py       - Запуск игры
|- config/       - Настройки и клавиши
|- engine/       - Рендер, физика, столкновения, ввод и сцена
|- game/         - Персонаж, уровни, двери, ключи и другие правила игры
|- resources/    - Карты, текстуры, шрифты и место для моделей
|- docs/         - Управление и работа с картами
|- tests/        - Тесты движка и игровых механик
`- tools/        - Генератор тестовых текстур
```
