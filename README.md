# Avacyn Game Jam

Игра на Python, Pygame и ModernGL. Начинаем в `peaceful`: мирной версии больницы
с общей для обоих миров геометрией трёх этажей. После разговора с человеком в кабинете врача загружается
`start` — трёхэтажная версия больницы с винтовой лестницей. Инвентарь переносится между мирами.

## Запуск

Проверенное окружение — Python 3.12. Из PowerShell в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для создания окружения команда `python` должна указывать на Python 3.12.
Если `.venv` уже подготовлена, достаточно последней команды; активация не нужна.

Для проверки союзника сразу в трёхэтажной больнице, с отображением маршрута:

```powershell
.\.venv\Scripts\python.exe main.py --level start --debug
```

F3 переключает панель диагностики и линии маршрутов. Союзник следует за игроком;
двери нужно открывать на E. Обычный запуск начинает с `peaceful`: поговорите
с врачом в дальнем кабинете (разговор также начинается при входе) и завершите диалог
для перехода в `start`.

## Акт 1 «Под софитами»

Обычный запуск начинает окончательную версию начальной главы: кабинет №104,
врач за столом, медицинское дело и зачитанные врачом вопросы с готовыми ответами.
После рычания, помех и чёрного экрана больница превращается в заброшенную.
Открытые двери, позиции героини и врача, инвентарь сохраняются. Доктор следует
за героиней, подстраивается под бег и ускоряется, если отстал.

В регистратуре откройте большой архив на E. В нём пять ящиков: 1975, 1978,
1981, 1985, 1990. В ящике 1981 найдите письмо «Новая жизнь», прочитайте его до
последней страницы и выберите ответ «Фильм» или «Книга». Закройте папку:
под ней обнаружится ключ от второго этажа. План и регистрационная карточка
доступны для чтения, но не требуются для получения ключа.

Ориентируйтесь по детскому плачу: на втором этаже он громче. На лестнице
однократно звучит реплика о порезе об ржавый гвоздь. У нужной двери нажмите E
(«Использовать ключ»); плач сразу прекращается. Осмотрите пустую люльку.
Камера остаётся на ней, пока звучит воспоминание дочери и матери с автоматическими
субтитрами. После двух тихих реплик героини, звука из коридора и затемнения
появляется «КОНЕЦ АКТА 1».

Реплики обычных разговоров появляются по буквам с голосовыми пиканиями:
E / Enter раскрывает текст, повторное нажатие продолжает разговор.
Выбор после письма — 1 / 2 или мышью. Голоса воспоминания синтезированы
на русском и записаны в WAV; для игры Windows TTS не требуется.
[Сценарий](docs/ACT0.md), [новые звуки и их источники](resources/audio/act0/README.md).

Сценарий хранится в `resources/story/hospital/acts/act0/`: технический ID
начальной главы сохранён, а на экране она называется актом 1.
`dialogue.json` содержит реплики, `act.json` — сцены и задачи,
`documents.json` — документы. [Редактирование сценария](docs/STORY.md).
Сюжетный прогресс хранится в памяти до перезапуска игры.

Прежние главы сохранены как отдельные точки для разработки:
`--level act1` запускает старую цепочку палат третьего этажа,
`--level act2` — мини-игру камер «Последние 30 секунд» в охране.
Новая начальная глава заканчивается у люльки и не запускает их автоматически.
Новая игра перемешивает фрагменты видеозаписи. Для продолжения сохранённой
мини-игры используйте `--level act2 --resume-archive`.
[Устройство мини-игры камер](docs/CCTV.md).

Больница озвучена: гул вентиляции и ламп, рабочий коридор в мирной версии,
пространственные скрипы дверей, сигналы приборов и далёкие шаги в заброшенной.
Фон приглушается в диалогах и затихает при превращении больницы.
[Звуки, источники CC0 и настройки](resources/audio/hospital/README.md).
В заброшенной больнице играет тихая мрачная музыка. При первом взгляде на кровь
у лестницы однократно звучит тревожный фортепианный акцент, музыка ненадолго
приглушается. [Музыка, авторство, лицензии и настройки](resources/audio/music/README.md).
Мелодия шкатулки, тиканье, шум телевизора и щелчок замка созданы для проекта:
[сценарные звуки](resources/audio/story/README.md).

При ходьбе по лестнице камера слегка дрожит, по краям кадра нарастает красная
виньетка и слышно тяжёлое дыхание. После остановки эффект плавно затихает.
После первого прохода героиня комментирует опасность лестниц; текст находится
в сцене `stairs_fear` файла `acts/act0/act.json`. Сила, частота и затухание тряски
настраиваются через `STAIR_SHAKE_*` в `config/settings.py`, нарастание и затухание
красной виньетки и дыхания — через `STAIR_STRESS_*`. Громкость дыхания задаётся
полем `breathing_volume` звукового профиля в `resources/audio/hospital/ambience.json`.

Для запуска сразу в редакторе:

```powershell
.\.venv\Scripts\python.exe main.py --creator
```

## Структура

- `config/` — настройки графики, персонажа и клавиш.
- `engine/` — рендер, физика, камеры, объекты и навигация.
- `game/campaign.py` — переходы между локациями и прогресс прохождения.
- `game/levels/location.py` — загрузка самостоятельных JSON-карт.
- `game/levels/hospital.py` — планировка и мебель первого этажа больницы.
- `game/levels/hospital_props.py` — диваны, растения, шкафы, тележки и детали рабочих мест.
- `game/levels/hospital_storeys.py` — этажи, перекрытия, проёмы и выходы с лестницы.
- `game/levels/spiral.py` — винтовой марш, ограждения и верхняя площадка.
- `game/levels/objects.py` — ключи, двери, враги и области выхода.
- `game/levels/cameras.py`, `creator.py`, `creator_lights.py` — данные редактора.
- `resources/levels/start.json` — трёхэтажная больница после перехода.
- `resources/levels/peaceful.json` — мирная больница с сюжетным ограничением подъёма и переходом после разговора.
- `resources/` — модели, текстуры и шрифты.
- `tests/` — проверки движка и игровых систем; вспомогательная геометрия
  для физики создаётся только внутри тестов и недоступна в игре.

Старые игровые и отладочные карты удалены. Для новой локации создайте отдельный
JSON-файл в `resources/levels/`. Выбор стартовой карты — `--level <имя>`;
по умолчанию используется `LEVEL_NAME` в `config/settings.py`.

[Карты и переходы](docs/LEVELS.md) · [Управление и Creator](docs/CONTROLS.md)

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe tools/check_story.py
```

Только навигация и сопровождение:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_navigation.py"
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_companions.py"
```
