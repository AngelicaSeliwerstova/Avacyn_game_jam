# Структура проекта

```text
gamek/
|- main.py                    - Собирает настройки, сцену и запускает игру
|- requirements.txt           - Зависимости Python
|- .gitignore                 - Что не сохраняем в Git
|- README.md                  - Карта проекта
|
|- config/                    - Настройки игры
|  |- settings.py             - Окно, графика, диагностика, движение и снег
|  `- controls.py             - Клавиши и кнопки мыши
|
|- engine/                    - Движок: общие системы без правил конкретной игры
|  |- core/
|  |  |- application.py       - Игровой цикл и связь между системами
|  |  `- window.py            - Окно, полный экран и показ кадра
|  |- debug/
|  |  |- profiler.py          - Средние FPS и время кадра, обновления и отрисовки
|  |  `- panel.py             - Переключаемая панель разработчика
|  |- controllers/
|  |  `- first_person.py      - Ходьба, бег и обзор от первого лица
|  |- input/
|  |  |- bindings.py          - Описание привязок управления
|  |  |- state.py             - Ввод одного кадра, включая бег и прыжок
|  |  `- keyboard_mouse.py    - Чтение клавиатуры, мыши и захват курсора
|  |- scene/
|  |  |- camera.py            - Положение камеры и перспектива
|  |  |- entity.py            - Общая сущность и интерфейс управления
|  |  |- transform.py         - Положение, поворот и масштаб сущности
|  |  |- model.py             - Ссылка и локальные параметры будущей модели, без загрузки
|  |  |- box.py               - Размеры блока, столкновения и имя материала
|  |  |- level.py             - Высоты и подписи этажей, геометрия, освещение и старт
|  |  |- lighting.py          - Источники света и фоновое освещение
|  |  `- tiled_level.py       - Загрузка карты из Tiled
|  |- collision/
|  |  |- aabb.py              - Прямоугольные границы препятствий
|  |  |- aabb3d.py            - Границы препятствий по высоте
|  |  |- world.py             - Столкновения и скольжение в плоскости XZ
|  |  `- world3d.py           - Объёмные столкновения, опоры, ступени и потолки
|  |- physics/
|  |  `- character.py         - Положение ног, присед, опора, прыжок и гравитация
|  |- particles/
|  |  `- snow.py              - Размещение снежинок и расчёт падения
|  |- rendering/
|  |  |- renderer.py          - Отрисовка сцены через ModernGL
|  |  |- render_target.py     - Буфер кадра с фиксированным разрешением
|  |  |- presentation.py      - Масштабирование кадра и поля по краям
|  |  |- postprocess.py       - Холодный оттенок и свечение ярких участков
|  |  |- lighting.py          - Атлас статичных теней и передача ламп в шейдер
|  |  |- light_grid.py        - Лампы, влияющие на каждую область уровня
|  |  |- visibility.py        - Проверка попадания блоков в обзор камеры
|  |  |- options.py           - Параметры отсечения и прохода глубины
|  |  |- snow.py              - Отрисовка снежинок с учётом стен
|  |  |- hud.py               - Текстовые панели поверх кадра
|  |  |- texture.py           - Материалы, загрузка PNG, mipmaps и фильтрация
|  |  |- meshes/
|  |  |  |- cube.py           - Геометрия куба
|  |  |  `- floor.py          - Геометрия и цвета пола
|  |  `- shaders/
|  |     |- color.vert       - Вершины, координаты текстур и оттенок граней
|  |     |- color.frag       - Текстуры, локальные источники света и тени
|  |     |- shadow.vert      - Геометрия с точки зрения лампы
|  |     |- shadow.frag      - Запись глубины для теней
|  |     |- present.vert     - Геометрия для вывода готового кадра
|  |     |- present.frag     - Вывод кадра без размытия
|  |     |- bloom_extract.frag - Выделение ярких областей
|  |     |- bloom_blur.frag   - Мягкое размытие свечения
|  |     |- cold_grade.frag   - Синий оттенок и смешивание со свечением
|  |     |- snow.vert        - Положение и размер снежинок на экране
|  |     `- snow.frag        - Цвет, прозрачность и мягкие края снежинок
|  `- raycasting/             - Место для будущих проверок лучом
|
|- game/                      - Конкретные сцены и правила игры
|  |- materials.py            - Пути к текстурам и настройки материалов
|  |- effects.py              - Настройки постобработки из конфигурации
|  |- entities/
|  |  |- player.py            - Тело, камера, управление, статус и место для модели
|  |  `- player_state.py      - Названия состояний движения персонажа
|  `- levels/
|     |- __init__.py          - Выбор уровня по имени
|     |- demo.py              - Тестовая площадка с кубом
|     |- corridor.py          - Подключение карты коридора
|     |- stairs.py            - Тестовая лестница с верхней площадкой
|     |- basement.py          - Пустой подвал и сетка потолочных ламп из данных карты
|     |- maze.py              - Сборка лабиринта, подвала, лестниц и светильников
|     `- maze_layout.py       - Чтение разметки и связи проходов между этажами
|
|- resources/                 - Карты и графические файлы
|  |- textures/
|  |  |- README.md            - Подключение текстур и параметры фильтрации
|  |  |- floors/              - Асфальт, грязная плитка и старое дерево
|  |  |- walls/               - Бетон, штукатурка, кирпич и больничная плитка
|  |  |- metals/              - Ржавый металл
|  |  `- samples/             - Первоначальные тестовые текстуры
|  |- models/
|  |  |- README.md            - Назначение папки и параметры будущих моделей
|  |  `- player/              - Место для будущего player.glb, пока без модели
|  |- levels/
|  |  |- corridor.tmx         - Стены и старт игрока, редактируются в Tiled
|  |  |- maze.json            - Два лабиринта, подвал, лампы, лестницы, старт и выход
|  |  `- README.md            - Формат карты и параметры большого уровня
|  `- tilesets/
|     |- wall.png             - Значок стены в редакторе Tiled
|     `- README.md            - Пояснение к набору тайлов
|
|- docs/
|  |- SPEC.md                 - Исходное техническое задание
|  |- EFFECTS.md              - Настройка холодного оттенка и свечения
|  |- LIGHTING.md             - Расстановка ламп, цвета, яркость и качество теней
|  |- DEBUG.md                - Панель F3 и хранение состояния игры и персонажа
|  `- PERFORMANCE.md          - Порядок отрисовки и проверка производительности
|- tests/                     - Тесты движения, ступеней, падения, столкновений, ввода и графики
|- tools/                     - Проверки с настоящим OpenGL-окном
|  |- check_rendering.py      - Масштабирование кадра, размер окна и полный экран
|  |- check_snow.py           - Движение снега и перекрытие стенами
|  |- check_textures.py       - Чёткость вблизи и mipmaps на настоящем GPU
|  |- check_maze.py           - Проход до выхода, план этажей и GPU-кадры
|  |- check_postprocess.py    - Проверка оттенка, ореолов и чёткости HUD на GPU
|  |- check_lighting.py       - Затухание света, тени от стен и перекрытий на GPU
|  |- check_shadow_acne.py    - Проверка полос самозатенения при косом свете
|  |- check_debug.py          - Панель F3 в игровом цикле, читаемость и масштабирование
|  |- check_performance.py    - Сравнение кадров и времени CPU/GPU с оптимизациями
|  |- check_basement.py       - Спуск в подвал, сотни ламп и проверка времени GPU
|  `- create_test_textures.py - Создание нейтральных тестовых PNG
`- artifacts/                 - Локальные скриншоты и отчёты, не попадают в Git
```

`__init__.py` - обозначает папку как Python-пакет. В дереве показан отдельно там, где отвечает за выбор уровня.
